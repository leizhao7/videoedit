02
Task generation

Turn any movie–trailer pair into RL tasks: A scalable data-generation pipeline

The pipeline matches trailer shots to the source movie, annotates the footage, and builds tasks with editing briefs, media inputs, and rubric-based reward functions. Applied to 49 real films, it generates 2,352 tasks; filtering retains 797 (716 training / 81 validation), with no films shared between splits.

The four independent task types are Content Selection (choose shots), Narrative Sequencing (order shots), Rough Cut (set clip boundaries), and Fine Cut (edit dialogue, music, and transitions over fixed picture timing).

Long-horizon multimodal agents

RL Training

Our runtime combines SkyRL training, vLLM inference, and an OpenCode agent harness for repeated visual inspection, reasoning, and editing-tool use. Qwen3.5-9B rollouts support up to 100 turns and 128K tokens of context. We implement three methods with feedback at different granularities:

Outcome-only GRPO

Run training

Setup & full guide

After setup, choose GRPO, GRPO+PRM, or OPSD in your configuration, then check it and run a two-update smoke test.

export EDITING_TRAINING_CONFIG=/path/to/training.toml
python -m modal run training/modal_train.py --action check
python -m modal run training/modal_train.py --action smoke --steps 2

The smoke test uses 8 H200 GPUs. The released GPU launch configuration has not yet been verified end to end.

04
Findings

When does finer feedback help?

We compare trajectory-level rewards,
turn-level feedback, and token-level distillation.

01

It helps more complex tasks.

Decaying process rewards improves Fine Cut by 45.4% relative to outcome-only GRPO. On the three other task types, GRPO remains competitive.

02

It can reward the wrong things.

A fixed process weight eventually encourages redundant actions while completion suffers. Decay lowers truncation from 44.1% to 6.2%.

03

It shapes how an agent works.

With decayed process rewards, more visual inspection, longer reasoning, and more self-correction markers accompany the best overall score in our 9B comparison.

TOKEN-LEVEL SIGNALS

Denser supervision is not sufficient: on-policy self-distillation yields limited or unstable gains and is sensitive to the privileged information given to the teacher.
